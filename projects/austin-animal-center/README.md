## What we're working on

Our team is working with Austin Animal Center intake and outcome records. The project involves cleaning and restructuring the data, developing research questions, and exploring patterns.

The final question, analysis sample, and models will be documented alongside the submitted work. This overview does not report findings before they are ready.

## Planned documentation and analysis checks

1. Record the exact dataset releases, download dates, coverage, and variable definitions.
2. Establish what a row represents in each file before joining intake and outcome records.
3. Check identifiers, duplicates, repeated visits, date consistency, and missing values.
4. Document any join keys, unmatched records, exclusions, and changes in row counts.
5. Define the analysis sample and outcomes before presenting comparisons.
6. Produce exploratory plots with denominators, units, and clear category definitions.
7. Explain what patterns suggest, which explanations remain uncertain, and what further analysis would be useful.

These are checks to complete and document, not a claim that all have already been performed.
